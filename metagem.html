What it does

From metagenomes to community metabolism

metaGEM turns raw shotgun-metagenomic reads into community-level metabolic predictions, end-to-end and reproducibly. It chains best-in-class tools into a single Snakemake DAG so a researcher can submit one job to a Slurm cluster and pick up genome-scale metabolic models on the other side.

The pipeline runs quality control with fastp, assembles reads with MEGAHIT and metaSPAdes, bins with CONCOCT and MetaBAT2, consolidates MAGs with MetaWRAP, assigns taxonomy with GTDB-Tk, reconstructs models with CarveMe, and simulates community metabolism with SMETANA.

Built during my PhD at the Patil lab (MRC Toxicology Unit, Cambridge); originally deployed at EMBL Heidelberg. Released under the MIT licence; still actively maintained.

Quick start

Get metaGEM running

{% highlight bash %} # clone and enter git clone https://github.com/franciscozorrilla/metaGEM.git cd metaGEM # create the environment bash env_setup.sh # dry-run on the bundled toy dataset snakemake -n -j 4 -s Snakefile # real run on a Slurm cluster (set --cluster-config first) snakemake -j 100 --cluster-config config/cluster.yaml --cluster sbatch {% endhighlight %}

Full installation, tutorials, and per-step walkthroughs live in the wiki.

Why it matters

Designed for industry-scale workflows

Before metaGEM, going from raw metagenomic data to a community metabolic model required gluing together a dozen tools by hand and burning through HPC time on failed runs. metaGEM packages that workflow in a Snakemake DAG with reproducible environments, sensible defaults, and HPC-aware parallelism.

It's been used to build 14,000+ genome-scale metabolic models across published studies on soil, gut, ocean, and clinical microbiomes — at a scale that informs industrial applications like SynCom design, biocatalyst discovery, fermentation optimization, and bioremediation.
